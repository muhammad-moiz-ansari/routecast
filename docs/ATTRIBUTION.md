# Source attribution and distribution notices

RouteCast branding uses the three user-supplied 512×512 PNGs in frontend/public: favicon-light.png for light surfaces, favicon-dark.png for dark surfaces, and favicon-white.png on the blue closing section. The shared brand component and theme-aware tab icon reference these local files directly.

GSAP 3.15.1 powers the home capability marquee. Its distributed README copyright and [standard no-charge licence reference](https://gsap.com/standard-license) are retained in generated browser dependency notices. It is not an MIT-licensed dependency. The official terms permit website animation; RouteCast does not use it as a visual animation authoring tool.

Reviewed 9 November 2026. This records the implemented sources and observed license metadata, not a legal certification or permission to deploy under an account's terms.

`npm run notices` generates browser notices from the locked installed production packages; `npm run build` checks the file for drift. Most packages include LICENSE/NOTICE files. murmurhash-js includes its MIT text in README.md. react-remove-scroll-bar 2.3.8 omits its full text from the npm archive: a copy of the upstream [LICENSE](https://raw.githubusercontent.com/theKashey/react-remove-scroll-bar/master/LICENSE), retrieved 9 November 2026, is retained in frontend/licenses and used only for that exact package version. Review this fallback when changing versions. No registry credential or private source was downloaded. Development/test tooling is excluded from browser notices.

RouteCast's supplied weather/load assessment and ranking rules are documented in RISK_RULES.md; they are not provider endorsements or certified navigation guidance. Synthetic fixtures are labeled and development/test only. No proprietary branding, copied screenshots, external photos or generated image assets were added.

UI-1 interaction follow-up: the user-supplied [React Bits Holo Card reference](https://reactbits.dev/c/components/holo-card) and official upstream component/CSS were reviewed for visual direction. RouteCast's HoloCard is an original CSS/DOM implementation of restrained foil and pointer tilt; no upstream shader/source code, image assets or new npm dependencies were copied. Landing example weather/workflow visuals and values are authored illustrations, explicitly labeled and unrelated to live provider output.

UI-2: [React Bits Specular Button](https://reactbits.dev/c/components/specular-button) and official upstream TSX/CSS were reviewed for the user's requested primary-CTA effect. SpecularAction implements an original lightweight CSS/DOM rim treatment with no upstream shader/code/assets copied. No new packages were added; the installed production notice inventory remains 71 packages. Existing routing/weather/map attribution remains visible in the redesigned workspace and detail views.
